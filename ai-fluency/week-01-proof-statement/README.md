## Notes

- File naming inside this folder is prefixed by assignment (`fl-01-*`, `fl-02-*`, ...) specifically to avoid collisions once more than one assignment's files live here.
- **Screenshots follow the same rule**: `screenshots/fl-01-claude-project.png`, not an unprefixed generic name — once a second assignment has its own screenshot, an unprefixed `screenshot.png` becomes ambiguous immediately.
- Each assignment's `-notes.md` file follows [`../../templates/week-template.md`](../../templates/week-template.md); the actual submitted deliverable stays in its own separate file, unmodified.
