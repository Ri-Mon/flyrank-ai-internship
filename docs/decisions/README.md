# Decision Records

Short records of real technical decisions, written when the decision is made — not reconstructed later from memory. This is the single best place for "why did you choose X" interview answers to live, since it's captured with actual context instead of hindsight.

One file per decision: `NNNN-short-title.md`, numbered sequentially, never renumbered even if a later decision reverses an earlier one (the old one just gets marked Superseded).

## Template

```markdown
# NNNN. [Short title of the decision]

**Date:** yyyy-mm-dd
**Status:** Proposed / Accepted / Superseded by NNNN

## Context

What problem or choice am I facing? What constraints matter (skill level, time,
hosting, future plans)?

## Options considered

1. **Option A** — pros / cons
2. **Option B** — pros / cons
3. **Option C** — pros / cons

## Decision

Which option, stated plainly.

## Why

The actual reasoning — this is the part that matters most for interviews.

## Consequences

What this makes easier, what it makes harder, what I'm accepting as a trade-off.
```
