# Assets

Cross-track visual material that doesn't belong inside a single week/module folder — things referenced from the root README or from more than one place.

Examples: enrollment confirmation, FlyRank credential/certificate image, capstone demo GIF, any diagram used in more than one README.

**Not for:** screenshots specific to a single assignment — those stay inside that assignment's own folder, next to the write-up they support, so the evidence lives with the claim it's backing up.

```
assets/
├── certificates/     # credential image once earned, verification screenshot
└── diagrams/         # any cross-track diagram (e.g. repo structure visual, if ever made)
```
